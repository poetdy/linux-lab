# Урок 03. Процессы и службы

## Цель
Научиться находить нужный процесс, останавливать его без лишнего ущерба и разбираться, почему служба ведет себя не так, как ожидается.

## Что тренируем
- `ps aux`
- `pgrep`, `pkill`
- `top`
- `kill`
- `jobs`, `bg`, `fg`, `nohup`
- `systemctl status`, `systemctl restart`

## Основные идеи
Процесс и служба — не одно и то же. Процесс можно искать через `ps`, а за жизненным циклом службы удобнее следить через `systemctl`.

`kill PID` посылает сигнал процессу. Сначала лучше использовать мягкое завершение, а не `-9`.

`pgrep -af name` часто быстрее, чем длинный `ps | grep`.

## Мини-примеры
```bash
ps aux | grep python
pgrep -af sleep
systemctl status ssh
```

## Типовые ошибки
- Убивать не тот PID.
- Сразу использовать `kill -9`.
- Искать проблему службы только через `ps`, не открывая `systemctl status` и журналы.
