# Практика

## Подготовка
```bash
bash ~/linux-lab/tasks/03-processes/setup.sh
cd ~/linux-lab/services/process-lab
```

## Разогрев
1. Найди процессы `sleep`, запущенные для лаборатории.
2. Определи их PID через `pgrep` и `ps`.
3. Посмотри, какой из них дольше всего живет.

## Упражнения
1. Останови лабораторный процесс без `kill -9`.
2. Запусти его снова через `./start-worker.sh`.
3. Открой `broken-service.sh` и пойми, почему он сразу завершается.
4. Исправь команду в `broken-service.sh`, чтобы скрипт отрабатывал успешно.

## Мини-кейс
Есть «служба», которая не держится в работе. Разберись, где ошибка запуска и как ее исправить, не ломая остальные файлы.
