# Урок 04. Сеть

## Цель
Научиться быстро понимать: есть ли маршрут, слушает ли порт, отвечает ли сервис и чем отличаются типичные сетевые сбои.

## Что тренируем
- `ip addr`
- `ip route`
- `ss -tulpn`
- `ping`
- `curl -I`
- `wget -qO-`

## Основные идеи
Сетевую проблему лучше разбирать по слоям: адрес, маршрут, порт, ответ сервиса.

`ss -tulpn` показывает, какие порты слушаются локально.

`curl -I http://127.0.0.1:18080` помогает быстро увидеть HTTP-ответ без полного тела.

## Мини-примеры
```bash
ip addr
ss -tulpn
curl -I http://127.0.0.1:18080
```

## Типовые ошибки
- Проверять удаленный сервис, не убедившись, что локально вообще кто-то слушает порт.
- Путать `connection refused` и `timeout`.
- Делать вывод по одному `ping`, хотя HTTP может быть сломан отдельно.
