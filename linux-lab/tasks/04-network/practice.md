# Практика

## Подготовка
```bash
bash ~/linux-lab/tasks/04-network/setup.sh
```

## Разогрев
1. Покажи IP-адреса сервера.
2. Посмотри таблицу маршрутов.
3. Найди лабораторный порт через `ss -tulpn`.

## Упражнения
1. Убедись, что локальный HTTP-сервис отвечает на `127.0.0.1:18080`.
2. Получи заголовки ответа через `curl -I`.
3. Получи тело ответа через `curl` или `wget`.
4. Сравни, чем будет отличаться ошибка при обращении к закрытому порту `18081`.

## Мини-кейс
Тебе дали адрес и сказали: «сервис не работает». Твоя задача — доказать, проблема в DNS, в маршруте, в порту или в самом приложении.
