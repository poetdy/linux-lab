# Практика

## Подготовка
```bash
bash ~/linux-lab/tasks/06-ssh/setup.sh
cd ~/linux-lab/broken/ssh-lab
```

## Разогрев
1. Открой `config.sample` и найди ошибку в пути к ключу.
2. Посмотри права на `.ssh` и `authorized_keys` в лабораторной копии.
3. Определи, почему такая конфигурация вызовет проблемы.

## Упражнения
1. Исправь `config.sample`, чтобы он ссылался на существующий лабораторный ключ.
2. Исправь права каталога `.ssh` на `700`.
3. Исправь права файла `authorized_keys` на `600`.
4. Проверь итог через `stat` и чтение файла.

## Мини-кейс
У тебя есть «сломанный» SSH-набор в лабораторной папке. Приведи его в вид, который прошел бы базовую проверку безопасности.

## Проверка
```bash
bash ~/linux-lab/tasks/06-ssh/verify.sh
```
