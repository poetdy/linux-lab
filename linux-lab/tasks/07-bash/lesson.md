# Урок 07. Bash, пайпы и фильтрация

## Цель
Научиться собирать полезные команды из простых блоков: фильтровать, преобразовывать и передавать данные дальше по конвейеру.

## Что тренируем
- пайпы `|`
- перенаправление `>` и `>>`
- `grep`
- `sed`
- `awk`
- `xargs`
- подстановку `$(...)`

## Основные идеи
Сила Bash не в одной большой команде, а в умении связать несколько простых команд в понятный поток.

`grep` фильтрует, `sed` заменяет, `awk` собирает поля и считает.

Перед записью в файл полезно сначала увидеть результат на экране.

## Мини-примеры
```bash
grep ERROR app.log | awk '{print $4, $5}'
ls *.log | xargs -n1 wc -l
DATE=$(date +%F)
```

## Типовые ошибки
- Перезаписывать файл через `>` там, где нужен `>>`.
- Путаться в полях `awk`.
- Делать слишком длинный конвейер без промежуточной проверки.
