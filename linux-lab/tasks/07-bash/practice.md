# Практика

## Подготовка
```bash
bash ~/linux-lab/tasks/07-bash/setup.sh
cd ~/linux-lab/sandbox/bash-lab
```

## Разогрев
1. Найди все строки с `ERROR`.
2. Выведи только путь запроса из лабораторного лога.
3. Посчитай, сколько раз встречается `/api/report`.

## Упражнения
1. Создай файл `error-summary.txt` только со строками ошибок.
2. Создай файл `paths.txt` только со списком путей запросов.
3. Создай файл `report-count.txt`, в котором будет число обращений к `/api/report`.
4. С помощью конвейера выведи только коды ответа и количество их повторений.

## Мини-кейс
Из сырого лога нужно быстро собрать короткий отчет для коллеги, не открывая редактор и не правя файл вручную.
