# Самопроверка

Проверь себя без подсказок:
- В каталоге `organized/docs` лежат только текстовые файлы.
- В `organized/images` лежат только изображения.
- В `organized/logs` лежат только журналы.
- В `organized/archive` есть копия `report-final.txt`.
- Архив `organized.tar.gz` существует и содержит каталог `organized/`.
