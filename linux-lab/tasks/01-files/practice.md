# Практика

## Подготовка
Запусти:
```bash
bash ~/linux-lab/tasks/01-files/setup.sh
cd ~/linux-lab/sandbox/files-lab
```

## Разогрев
1. Покажи текущую директорию.
2. Выведи полный список файлов, включая скрытые.
3. Найди все файлы с расширением `.log`.
4. Определи самый тяжелый каталог в текущей директории.

## Упражнения
1. Создай структуру `organized/docs`, `organized/images`, `organized/logs`, `organized/archive`.
2. Перемести все `.txt` файлы в `organized/docs`.
3. Перемести все `.jpg` и `.png` в `organized/images`.
4. Перемести все `.log` в `organized/logs`.
5. Найди файл `report-final.txt` и скопируй его в `organized/archive`.
6. Создай архив `organized.tar.gz` из каталога `organized`.
7. Проверь содержимое архива без распаковки.

## Мини-кейс
У тебя есть беспорядочная рабочая папка. Приведи ее к понятной структуре так, чтобы:
- документы были отдельно,
- изображения были отдельно,
- журналы были отдельно,
- архив содержал уже собранный каталог `organized`.

Запусти:
