# Урок 01. Файлы и директории

## Цель
Научиться уверенно перемещаться по файловой системе, искать нужные данные, собирать аккуратную структуру каталогов и упаковывать результат.

## Что тренируем
- `pwd`, `cd`, `ls -la`
- `mkdir -p`, `touch`
- `cp`, `mv`, `rm`, `rmdir`
- `find`, `du -sh`, `sort`
- `tar -czf`, `tar -tf`

## Ключевые приемы
`pwd` показывает, где ты находишься сейчас.

`ls -la` полезен почти всегда: видно скрытые файлы, права и владельца.

`mkdir -p a/b/c` создает всю цепочку каталогов сразу.

`find . -type f -name "*.log"` ищет файлы по маске.

`du -sh * | sort -h` помогает понять, что занимает место.

`tar -czf result.tar.gz папка/` упаковывает каталог в архив.

## Мини-примеры
```bash
find . -type f -name "*.txt"
du -sh * | sort -h
tar -tf backup.tar.gz
```

## Типовые ошибки
- Выполнять `rm` не в той директории.
- Путать `cp` и `mv`.
- Создавать архив, не проверив его содержимое через `tar -tf`.
- Искать файлы из неправильной точки входа.
