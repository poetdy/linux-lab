# Практика

## Подготовка
```bash
bash ~/linux-lab/tasks/08-docker/setup.sh
cd ~/linux-lab/broken/docker-lab
```

## Разогрев
1. Проверь, установлен ли Docker через `docker --version`.
2. Если Docker есть, посмотри список контейнеров и образов.
3. Если Docker нет, открой `docker-scenarios.md` и пройди задания как разбор кейсов.

## Упражнения
1. Объясни, какой командой посмотреть завершившиеся контейнеры.
2. Объясни, как увидеть логи контейнера.
3. Если Docker доступен, запусти тестовый контейнер с пробросом порта.
4. Если Docker недоступен, выпиши команды, которые использовал бы для диагностики.

## Мини-кейс
Приложение в контейнере «не работает». Твоя задача — назвать правильный порядок проверки: статус, логи, порты, тома, переменные окружения.

## Проверка
```bash
bash ~/linux-lab/tasks/08-docker/verify.sh
```
