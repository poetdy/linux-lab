# Урок 08. Docker

## Цель
Понять базовые операции Docker и уметь разбирать типовые проблемы контейнера: почему он не стартует, не слушает порт или теряет данные.

## Что тренируем
- `docker images`
- `docker ps -a`
- `docker logs`
- `docker exec`
- `docker run -p`
- `docker volume`

## Основные идеи
Контейнер — это отдельный процесс с собственным окружением. Если он завершился, первым делом смотри `docker ps -a` и `docker logs`.

Порты и тома — две самые частые точки ошибки в базовых сценариях.

Если Docker недоступен, тему все равно полезно пройти как теоретико-практический разбор команд и типовых кейсов.

## Мини-примеры
```bash
docker ps -a
docker logs myapp
docker run -d -p 8080:80 nginx
```

## Типовые ошибки
- Ожидать, что контейнер сам по себе сохранит данные без тома.
- Проверять приложение, не посмотрев `docker logs`.
- Путать порт контейнера и порт хоста.
