# Урок 02. Права доступа

## Цель
Понять, как Linux решает, кто может читать, изменять и запускать файлы и каталоги.

## Что тренируем
- `ls -l`
- `chmod`
- `chown`
- `chgrp`
- `umask`
- `stat`

## Основные идеи
У файла и каталога есть владелец, группа и права для трех категорий: владелец, группа, остальные.

Для каталогов бит `x` означает право входить внутрь каталога.

`chmod 640 file.txt` задает права цифрами.

`chmod u+x script.sh` меняет права символически.

`stat file.txt` удобно использовать, когда нужно увидеть точные права и владельца.

## Мини-примеры
```bash
ls -l
chmod u+x deploy.sh
stat secret.txt
```

## Типовые ошибки
- Давать `777` там, где это не нужно.
- Забывать, что каталог без `x` нельзя открыть даже при наличии `r`.
- Проверять только права файла, забыв про права родительской директории.
