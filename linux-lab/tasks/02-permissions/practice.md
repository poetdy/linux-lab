# Практика

## Подготовка
```bash
bash ~/linux-lab/tasks/02-permissions/setup.sh
cd ~/linux-lab/sandbox/permissions-lab
```

## Разогрев
1. Посмотри права всех файлов и каталогов.
2. Найди файл, который нельзя выполнить как скрипт.
3. Найди каталог, в который нельзя зайти.

## Упражнения
1. Сделай `run-report.sh` исполняемым только для владельца.
2. Настрой `team.txt` так, чтобы владелец мог читать и писать, остальные только читать.
3. Исправь каталог `restricted-dir`, чтобы в него можно было зайти и прочитать содержимое.
4. Проверь итог через `stat`.

## Мини-кейс
Представь, что тебе передали каталог с неправильными правами. Твоя задача — починить доступ, не открывая файлы шире, чем нужно.
