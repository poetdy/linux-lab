# Урок 05. Логи

## Цель
Научиться находить полезные записи в шумном потоке логов и быстро связывать ошибку с причиной.

## Что тренируем
- `tail -f`
- `less`
- `grep`
- `grep -i`
- `journalctl -u`
- `journalctl --since`

## Основные идеи
Логи удобнее читать не целиком, а с фильтрацией по времени, уровню, шаблону или службе.

`tail -f` полезен, когда ты сам воспроизводишь проблему.

`grep -i error app.log` — базовый фильтр для ошибок.

## Мини-примеры
```bash
tail -f app.log
grep -i error app.log
journalctl -u ssh --since '10 minutes ago'
```

## Типовые ошибки
- Читать слишком большой файл без фильтрации.
- Искать только слово `error`, игнорируя `failed`, `timeout`, `denied`.
- Делать вывод без привязки ко времени инцидента.
