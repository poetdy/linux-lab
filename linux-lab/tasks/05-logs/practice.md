# Практика

## Подготовка
```bash
bash ~/linux-lab/tasks/05-logs/setup.sh
cd ~/linux-lab/services/log-lab
```

## Разогрев
1. Посмотри последние строки `app.log`.
2. Найди все строки с ошибками без учета регистра.
3. Отфильтруй только неуспешные HTTP-запросы.

## Упражнения
1. Найди самую позднюю строку с `ERROR`.
2. Определи, какой путь чаще всего завершался кодом `500`.
3. Сохрани все ошибки в файл `errors-only.log`.
4. Сохрани список неуспешных запросов в `failed-requests.log`.

## Мини-кейс
По логам нужно понять, что ломает приложение: авторизация, база или маршрутизация. Используй только командную строку.
