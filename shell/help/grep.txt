# grep

Коротко: ищет строки по шаблону.

Быстрые примеры:
- `grep error app.log` — найти строки с `error`
- `grep -i warning app.log` — поиск без учета регистра
- `grep -n ssh config.sample` — показать номера строк
- `grep -R "listen" .` — искать рекурсивно

Полезные ключи:
- `-i` — игнорировать регистр
- `-n` — показывать номера строк
- `-R` — искать по дереву каталогов
- `-v` — показать строки, которые не совпали
