# mkdir

Коротко: создает каталоги.

Быстрые примеры:
- `mkdir docs` — создать один каталог
- `mkdir docs images logs` — создать несколько каталогов
- `mkdir -p organized/docs` — создать вложенную структуру целиком

Что помнить:
- `-p` особенно полезен в учебных задачах с глубокой структурой;
- без `-p` команда ожидает, что родительские каталоги уже существуют.

Проверь дальше:
- `man mkdir`
- `hman mkdir`
- тема `~/linux-lab/tasks/01-files`
