# sort

Коротко: сортирует строки.

Быстрые примеры:
- `sort names.txt` — отсортировать строки по алфавиту
- `sort -h sizes.txt` — сортировка чисел с суффиксами вроде K, M, G
- `du -sh * | sort -h` — от меньшего размера к большему

Когда полезен:
- нужно найти самый тяжелый каталог;
- хочется упорядочить вывод перед анализом;
- надо сравнить список файлов или строк.

Проверь дальше:
- `man sort`
- `hman sort`
- тема `~/linux-lab/tasks/01-files`
