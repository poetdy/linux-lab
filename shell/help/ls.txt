# ls

Коротко: показывает содержимое каталога.

Быстрые примеры:
- `ls` — простой список файлов
- `ls -a` — включая скрытые элементы
- `ls -la` — подробный список со скрытыми файлами
- `ls -lah` — то же, но размеры удобнее читать человеку

Что помнить:
- скрытые файлы в Linux начинаются с точки;
- `-l` показывает права, владельца и размер;
- `-a` нужен для полной картины в учебной папке.

Проверь дальше:
