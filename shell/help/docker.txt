# docker

Коротко: работает с контейнерами, образами и журналами контейнеров.

Быстрые примеры:
- `docker ps` — запущенные контейнеры
- `docker ps -a` — все контейнеры
- `docker logs <container>` — журнал контейнера
- `docker exec -it <container> sh` — войти внутрь контейнера
- `docker inspect <container>` — подробная информация

Что обычно проверяют первым:
- запущен ли контейнер;
- не завершился ли он с ошибкой;
- правильно ли проброшены порты;
- сохранились ли данные во volume.

Проверь дальше:
- `man docker`
- `hman docker`
- тема `~/linux-lab/tasks/08-docker`
