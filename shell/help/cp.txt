# cp

Коротко: копирует файлы и каталоги.

Быстрые примеры:
- `cp file.txt backup.txt` — создать копию файла
- `cp file.txt archive/` — скопировать файл в каталог
- `cp -r dir copy-dir` — скопировать каталог рекурсивно

Что помнить:
- `cp` оставляет исходный объект на месте;
- это главное отличие от `mv`;
- для каталогов обычно нужен `-r`.
