# chmod

Коротко: меняет права доступа к файлам и каталогам.

Быстрые примеры:
- `chmod 644 file.txt` — чтение для всех, запись только владельцу
- `chmod 755 script.sh` — исполняемый файл
- `chmod u+x script.sh` — добавить владельцу право на запуск
- `chmod -R 755 dir` — рекурсивно изменить права в каталоге

Что помнить:
- Для каталога `x` означает право зайти внутрь.
- Для скриптов часто нужен режим `755` или точечное `u+x`.
- Не давай лишние права без необходимости.
