# tar

Коротко: собирает архивы и распаковывает их.

Быстрые примеры:
- `tar -cf backup.tar dir/` — создать tar-архив
- `tar -xf backup.tar` — распаковать архив
- `tar -tf backup.tar` — посмотреть содержимое
- `tar -czf backup.tar.gz dir/` — создать gzip-архив

Как читать ключи:
- `c` — создать
- `x` — распаковать
- `t` — показать список файлов
- `f` — работать с файлом архива
- `z` — использовать gzip

Проверь дальше:
- `man tar`
- `hman tar`
