# ip

Коротко: современная команда для просмотра адресов, маршрутов и интерфейсов.

Быстрые примеры:
- `ip addr` — все адреса и интерфейсы
- `ip -4 addr` — только IPv4
- `ip route` — таблица маршрутов
- `ip link` — состояние сетевых интерфейсов

Практический минимум:
- смотри `ip addr`, когда нужно узнать адреса;
- смотри `ip route`, когда нужно понять маршрут по умолчанию.

Проверь дальше:
- `man ip`
- `hman ip`
- тема `~/linux-lab/tasks/04-network`
