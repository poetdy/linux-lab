# Linux Lab

Linux Lab — это публичный учебный монорепозиторий с практическим полигоном по Linux. В центре проекта находится не деплой сам по себе, а содержимое курса: темы, упражнения, проверки, shell-подсказки и сценарии, которые помогают руками наработать уверенность в терминале.

Проект рассчитан на тех, кто хочет последовательно пройти путь от базовой навигации по файловой системе до диагностики процессов, сети, логов, SSH, Bash и Docker. Репозиторий устроен так, чтобы его можно было и установить на Debian-машину, и развивать как открытый набор учебных материалов.

## Что внутри

- `linux-lab/` — учебный контент, который разворачивается у пользователя в `~/linux-lab`
- `shell/` — shell-слой: welcome-скрипт, helper-функции, команда `menu` и lesson runner
- `docs/` — документация для сопровождающих и контрибьюторов
- `install.sh` — установка Linux Lab на Debian

## Темы Linux Lab

```text
01-files        файлы и директории
02-permissions  права доступа
03-processes    процессы и базовая работа со службами
04-network      адреса, порты и доступность сервисов
05-logs         чтение и фильтрация логов
06-ssh          ключи, config и типовые ошибки доступа
07-bash         пайпы, grep, sed, awk и обработка вывода
08-docker       базовые сценарии Docker и диагностика контейнеров
```

Внутри каждой темы ожидается единый набор файлов:

- `lesson.md`
- `practice.md`
- `checks.md`
- `setup.sh`
- `verify.sh`

В темах с интерактивным сопровождением рядом может лежать `runner.txt`.

## Установка

Минимальный путь установки на Debian:

```bash
git clone <repo-url> linux-lab-repo
cd linux-lab-repo
bash install.sh
exec bash
```

После установки Linux Lab появится в `~/linux-lab`, а shell-помощники станут доступны в новой сессии. Если вы подключаетесь по SSH, приветственный экран покажет, с чего начать.

Подробности по установке: [docs/install.md](docs/install.md)

После установки справка работает в три слоя:

- `tldr` и `h` сначала пытаются показать короткую русскую подсказку;
- `hman` пытается открыть `man` с русской локалью;
- если системного покрытия не хватает, Linux Lab показывает локальную офлайн-подсказку из репозитория.

Эту же layered help цепочку использует и lesson runner, когда внутри шага вызывается `help`.

## Как проходить обучение

Есть два нормальных режима прохождения темы.

Стандартный путь: откройте [linux-lab/README.md](linux-lab/README.md), перейдите в нужную тему, запустите `setup.sh`, выполните практику из `practice.md`, затем проверьте себя через `checks.md` и `verify.sh`.

Интерактивный путь: запустите `lesson 01-files`, чтобы пройти тему пошагово внутри shell. Runner показывает задание, при необходимости сам подготавливает среду урока, переводит в рабочий каталог темы и дополнительно понимает `hint`, `help`, `explain`, `check`, `skip` и `quit`.

На ранних шагах runner может мягко настаивать на нужной команде, а на поздних больше ориентироваться на корректный результат.

Рекомендуемый маршрут:

`01-files` → `02-permissions` → `03-processes` → `04-network` → `05-logs` → `06-ssh` → `07-bash` → `08-docker`

## Как участвовать в развитии

Linux Lab задуман как контентно-ориентированный репозиторий, поэтому основная зона улучшений — сами уроки, практические сценарии и проверки.

- Хотите поправить или усилить конкретную тему: редактируйте файлы в `linux-lab/tasks/<topic>/`
- Хотите изменить требования к структуре тем: начните с [docs/content-guide.md](docs/content-guide.md)
- Хотите предложить изменения по установке и shell-слою: смотрите `install.sh` и файлы в `shell/`

Общие правила контрибьюта описаны в [CONTRIBUTING.md](CONTRIBUTING.md).

## Честно о текущем состоянии

Это первая публичная базовая версия монорепозитория. В ней уже есть актуальный учебный контент, shell-слой онбординга, shell-помощники и Debian-установщик, но более широкий контур еще впереди:

- автоматизация SSH-provisioning
- web-terminal режим
- временные учебные пользователи
- автоматический reset учебной среды
