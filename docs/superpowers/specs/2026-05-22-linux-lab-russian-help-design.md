# Linux Lab Russian Help Design

Дата: 2026-05-22
Тема: гарантированная русская справка через `tldr`, `man` и локальный fallback

## Цель

Сделать так, чтобы после установки Linux Lab на Debian пользователь сразу получал:

- быстрые подсказки через `h` на русском;
- доступ к `man` с русской локалью и русским контентом там, где он доступен;
- гарантированный локальный fallback с русскими шпаргалками Linux Lab;
- предсказуемое поведение без зависимости только от внешних пакетов.

## Решение

Используется трехслойная схема справки:

1. `tldr` на русском как первый источник краткой помощи;
2. `man` с `LANG=ru_RU.UTF-8` как второй источник;
3. локальные русские подсказки Linux Lab как гарантированный fallback.

## Изменения в репозитории

### `install.sh`

Установщик должен:

- ставить `man-db`, `manpages`, `manpages-ru`, `locales`, `tree`;
- пытаться поставить клиент `tldr`, если пакет доступен;
- безопасно генерировать `ru_RU.UTF-8`, если локаль еще не подготовлена;
- печатать понятный статус на русском, если системный пакет `tldr` или `manpages-ru` недоступен.

### `shell/linux-lab.sh`

Команды должны работать так:

- `h команда`:
  - сначала пробует `tldr --language ru`;
  - затем `tldr` без явного языка;
  - затем `hman`;
  - затем локальную справку Linux Lab.
- `hman команда`:
  - запускает `man` с `LANG=ru_RU.UTF-8`.
- `hs слово`:
  - сначала ищет через `apropos`;
  - затем дополнительно показывает совпадения по локальной справке Linux Lab.

### Локальная справка Linux Lab

В репозитории появляется каталог с русскими офлайн-подсказками по основным командам и темам Linux Lab. Эти файлы являются гарантированным fallback, если:

- `tldr` не установлен;
- у команды нет русской `tldr`-страницы;
- системная `man`-страница на русском отсутствует.

## Ограничения

- Полное покрытие русского `man` зависит от наличия пакетов в целевом Debian.
- Полное покрытие русского `tldr` зависит от клиента и локальных данных.
- Linux Lab должен честно компенсировать эти ограничения собственными локальными шпаргалками.

## Критерии готовности

- После `install.sh` команды `lab`, `h`, `hman`, `hs`, `ll`, `ports`, `ip4` доступны в новой shell-сессии.
- `h find` и аналогичные базовые команды дают русский ответ хотя бы через один из слоев.
- Если системные пакеты не дают русский результат, пользователь все равно получает локальную русскую подсказку.
- Документация описывает это поведение без преувеличений.
