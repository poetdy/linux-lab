# Установка Linux Lab

## Поддерживаемая среда

Текущий установочный сценарий ориентирован на Debian 12+ и Debian-подобные системы с `apt`. Базовый путь использования — интерактивная shell-сессия по SSH или локальный терминал обычного пользователя.

## Что делает `install.sh`

Скрипт:

1. Проверяет, что запуск идет на Linux.
2. Проверяет наличие структуры репозитория рядом со скриптом.
3. При наличии `apt` пытается установить базовые пакеты, которые полезны для Linux Lab.
4. Копирует `linux-lab/` в `~/linux-lab`.
5. Устанавливает `shell/lab-welcome` в `~/.local/bin/lab-welcome`.
6. Устанавливает `shell/linux-lab.sh` в `~/.local/share/linux-lab/linux-lab.sh`.
7. Устанавливает lesson runner и его общую shell-библиотеку.
8. Устанавливает локальные help-файлы и wrapper `tldr` в пользовательский профиль.
9. Пытается подготовить `ru_RU.UTF-8`, `manpages-ru` и связанные пакеты справки.
10. Один раз добавляет в `~/.bashrc` блок подключения helper-файла.

## Как запустить

```bash
git clone <repo-url> linux-lab-repo
cd linux-lab-repo
bash install.sh
exec bash
```

Если вы входите на машину по SSH, после новой сессии сработает приветственный экран Linux Lab.

После новой shell-сессии становится доступен и интерактивный запуск тем через `lesson <topic>`, например `lesson 01-files`. Установщик также добавляет `~/.local/bin` в `PATH`, чтобы команды `lesson`, `tldr` и `lab-welcome` были доступны предсказуемо.

## Какие файлы появляются у пользователя

- `~/linux-lab/` — учебный полигон
- `~/.local/bin/lab-welcome` — welcome-скрипт
- `~/.local/bin/lesson` — команда запуска lesson runner
- `~/.local/bin/tldr` — wrapper Linux Lab для русских коротких подсказок
- `~/.local/share/linux-lab/linux-lab.sh` — shell helper-функции
- `~/.local/share/linux-lab/lesson-runner-lib.sh` — общая библиотека lesson runner
- `~/.local/share/linux-lab/help/` — локальные русские офлайн-подсказки
- блок в `~/.bashrc`, который подключает Linux Lab helper-файл

## Как устроена русская справка

После установки Linux Lab использует трехслойную схему:

1. `tldr` и `h` сначала пробуют короткую русскую подсказку.
2. `hman` пробует открыть `man` с `LANG=ru_RU.UTF-8`.
3. Если системный пакет или русская страница недоступны, Linux Lab показывает локальную подсказку из `~/.local/share/linux-lab/help/`.

Это дает предсказуемый офлайн fallback даже на тех Debian-системах, где покрытие русских manpages неполное.

Внутри lesson runner действие `help` должно использовать ту же цепочку, чтобы учебный режим и обычная shell-справка не расходились по поведению.

## Идемпотентность

`install.sh` можно запускать повторно. Скрипт:

- пересинхронизирует содержимое `~/linux-lab`
- перезапишет репозиторные shell-файлы актуальной версией
- обновит lesson runner и его общую библиотеку
- обновит локальные help-файлы Linux Lab
- не будет дублировать блок подключения в `.bashrc`

## Ограничения текущей версии

- Скрипт не создает отдельных учебных пользователей.
- Скрипт не поднимает web-terminal и не настраивает внешний SSH provisioning.
- Если у пользователя нет прав на `sudo`, пакетная часть и генерация локали могут быть пропущены, но копирование файлов и локальные подсказки Linux Lab все равно продолжатся.
